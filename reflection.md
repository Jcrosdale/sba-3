During the project, I encountered many challenges when it came to choosing between vanilla CSS and Bootstrap. I needed to double-check and refer to documentation to figure out what Bootstrap is best at handling and when to use vanilla CSS. As I kept going, I started getting the hang of it and could code almost half of the Bootstrap features with memorization. I also ran into a lot of issues when it came to the spacing of the different sections in the website. Finally, matching the design with Frontend Mentor’s original design was difficult without having Figma.

I began the challenge by keeping it as organized as possible. As a best practice, I decided to go with a mobile-first approach due to an increasing number of people accessing websites through devices other than a computer. It’s also easier to adjust the responsiveness from mobile to desktop than the other way around. Afterwards, I began on the semantic HTML structure and images. I would adjust the sections and break them into divs in case I needed more containers to organize it accurately.

If I had more time, I would have liked to add a JavaScript file and make it more interactive. I would have created different branches and links to other web pages. I also would have added more accessibility practices such as focus: hover, W3C Level AAA Testing, and ARIA attributes.
